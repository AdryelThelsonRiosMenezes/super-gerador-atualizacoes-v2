# Super Gerador de Atividades 2 — atualizações

Este repositório é o **canal de atualizações** da versão 2 do Super Gerador de Atividades.

- Em **[Releases](../../releases)** fica o instalador de cada versão (`Super-Gerador-de-Atividades-Setup-<versão>.exe`).
- O programa instalado consulta este canal sozinho, baixa a versão nova, **confere a impressão digital (SHA-256)** e se atualiza.
- Cada versão pode trazer um `novidades.json` com imagens de prévia, mostrado na janela de atualização.

Não há código-fonte nem dados de alunos aqui: apenas os instaladores e as novidades.

> A versão 1.x usa outro canal (`Super-gerador-atualizacoes`), mantido separado de propósito.
